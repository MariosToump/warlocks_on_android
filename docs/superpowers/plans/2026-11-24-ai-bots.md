# AI Bots Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bots that fight back (move, aim, dodge, avoid lava, use all spells), with 3 personalities and 3 difficulties.

**Architecture:** An `AIController` node child of a `Wizard` (like `PlayerController`) runs a utility-scoring think loop. `AIPersonality` (weights) and `AIProfile` (difficulty limits) are Resources. Lava safety runs every physics frame.

**Tech Stack:** Godot 4.7.2, GDScript. Headless tests: `godot --path . -s tools/<test>.gd`.

**Spec:** `docs/superpowers/specs/2026-11-24-ai-bots-design.md`

## Global Constraints
- GDScript only; no new art or animations.
- Bots never read player input, never perceive a projectile younger than `reaction_delay`, never bypass `Wizard.cast()` cooldowns.
- Hard: `aim_error_deg` > 0 and `reaction_delay` > 0.
- Free-for-all: any other living wizard is an enemy.
- Bots respawn 2 s after dying (existing `game.gd` behaviour).
- Godot exe: `D:\Godot\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe` (call it `$GODOT`).

## Review Focus
1. Bot knocked hard toward lava (by a fireball, 380+ impulse) near the edge — expect it to blink or walk back, not die every time. → test in Task 3.
2. Only enemy is dead / respawning — bot must idle-reposition, not crash on a freed or dead target. → test in Task 4.
3. Bot's own reflected fireball (after an enemy shield, `caster` changes) — bot must treat it as an enemy projectile then. → test in Task 3.
4. Target standing on the far side of lava — reposition must not path straight through lava. → covered by per-frame safety, test in Task 3.
5. Existing tests must still run: they reference `Wizards/DummyBlue` / `DummyGreen`. → Task 1 renames and updates them.

### Task 2: Perception, think loop, movement and fireball

**Files:** Modify `scripts/ai/ai_controller.gd`. Create `tools/test_ai.gd` (same harness style as `test_staff.gd`: `_place`, `_seconds`, `_check`, exit code = failures).

**Interfaces — Produces (on AIController):**
- `wizard: Wizard` (parent), `target: Wizard`, `current_action: String`.
- `_pick_target() -> Wizard` — nearest living enemy; score = distance − low-health bonus − near-lava bonus; +keep bonus for current.
- `_visible_projectiles() -> Array[Projectile]` — group `projectiles`, `caster != wizard`, `age >= profile.reaction_delay`.
- `_aim_at(w: Wizard, projectile_speed: float) -> Vector2` — leads by `lead_amount * w.velocity * (dist / speed)`, then rotates by `randf_range(-aim_error_deg, aim_error_deg)`.
- `ACTIONS: Array[String]`; per action `_score_<name>() -> float` and `_do_<name>() -> void`. Chosen = argmax(score × `personality.weights[name]`), current action gets +0.1.
- Think timer uses `profile.think_interval`; casts respect `cast_pause` since last cast.
- This task implements `reposition` and `fireball`.

### Task 3: Safety — lava, recover, dodge, shield

**Files:** Modify `scripts/ai/ai_controller.gd`, `tools/test_ai.gd`.

**Interfaces — Produces:**
- `_physics_process`: if `arena.is_lava_at(wizard.global_position + walk_velocity * 0.3)` redirect `move_target` toward arena centre (walk velocity = direction to `move_target` × `move_speed`).
- `_danger_projectile() -> Projectile` — visible projectile whose closest approach to the bot is < 20 px within 0.6 s; dodge roll (`dodge_chance`) cached per projectile instance id.
- Actions `dodge` (sidestep perpendicular, pick side whose point 40 px out is not lava and farther from lava), `recover` (score high when on lava or `knockback` points toward lava within ~0.5 s; blink toward centre if ready and on lava or knockback > 250), `shield` (danger projectile and dodge failed roll or no safe side, roll `shield_reflect_chance`).
